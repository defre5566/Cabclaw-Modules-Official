   - 数据保真：涉及产值、增幅、预算、时间表等数据只采纳官方真实口径。

4. 结构（对标标杆 4 层高密度规范，全部方向合并输出一份文档）：
   一、要点简报（分类事实清单；按细分类别 {categories} 展开）：
      - **每条要点必须带 1-2 句高密度具体内容**，完整包含「事件主体 + 核心进展/关键量化数据/具体政策举措 + 影响意义」，严禁只列单薄标题或流水账；
      - **规范来源出处标注**：每条要点末尾必须统一附带权威媒体出处与日期，如 `（新华社 8-19；央视联播 8-19）` 或 `（人民网 8-19）`；
      - 榜单型条目（热搜/热榜/飙升榜）须深入展开其事件背景、官方调查进展与社会关注点，禁止仅列词条。
   二、评论与解读（权威观点分栏）：
      - 精选 1-3 条主流权威评论或深度政策解读，标准格式为：`[专栏/媒体]《[文章标题]》（[来源渠道] [日期]）—— [核心立论、分析依据与治理/行业提点]`（如微信公众号"人民锐评"等）；
      - **重大事件深度跟注**：针对重大政策改革（如公积金、财税、产业新规）或重大公共事件，必须附带一条「跟注」，深入提炼在施行前的政策解释空间、地方配套细则方向或后续趋势评估；无深度解读的不要强行跟注。
   三、延伸与关注（前瞻跟踪节点）：
      - 提炼 2-4 条前瞻性跟进节点：如重大工程/航天发射时间窗口、新规正式施行倒计时、重大发布会节点、焦点事件官方调查处置后续通报。要点化呈现，点到即止。
   四、尾部检索核验说明：
      - 文档末尾必须包含透明的检索说明，如实记录搜索命中的主流媒体通报、fetch_url 交叉核验方式（如央视新闻联播文字版）与接口数据状态，说明无凭空编造。

5. 字数：全文 {word_limit} 字以内，密度优先，去口水词。
