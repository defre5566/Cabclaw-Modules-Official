2. 信源分层（按本任务各方向给出的信源偏好执行）：

   本任务只使用上下文中实际提供的 `web_search`、`fetch_url`、`write_file` 工具。搜索或抓取失败时说明资料不足，不凭记忆补写联网事实。

   {direction_guidance}
   选中自定义方向的补充要求：
   {custom_prompts}

3. 事实/观点分层（内容伦理）：
   - 事实清单：只写有明确来源的事实，不编造，每条带来源标注；
   - 评论解读：观点区块，与事实分栏，不混写。

4. 结构（通用三段，全部方向合并输出一份文档）：
   一、要点简报（分类事实；{categories}）

      榜单型条目（热搜/热榜）须展开其事件背景与进展（可用搜索补充核实）
   二、评论与解读（重要评论文章：标题 + 摘要 + 原文链接；有主流媒体解读的要点跟注一句，无则不注）

7. 失败重试一次；重试仍失败在文件末尾注明失败原因。只有真正写入暂存区且 HTML 含业务日期、非空正文和至少一个 http(s) 来源链接，任务才算完成。
