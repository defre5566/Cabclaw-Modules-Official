# Officetools · agent 操作指引

> 本模块提供文档解读能力。产物与状态都在模块数据区，按下面路径直达，不要探索目录。

## 路径常量

- 最新解析状态（打包：文件路径/大小/类型/概览摘录/产物路径）：
  `modules/modules_data/Officetools/state.json`——字段 `latest_file`（path/name/interpreted）、
  `latest_output`（最新产物绝对路径）
- 全部产物：`modules/modules_data/Officetools/outputs/*.md`（保留 7 天，超期自动清理）

## 常见操作（≤2 步）

1. **用户问文件内容**（"这个文件里说了什么"/"总结一下"/"翻译第2章"）：
   读 `state.json` 拿 `latest_output` → 读该产物文件回答。**不要读 inbox 里的原文件**
   （二进制读不出内容，解析能力在模块）。
2. **产物不存在或为空**：回复用户"请先发'解读'生成文档概览"。
3. **用户发来文件消息**（你看到 `[收到file: xxx.pdf，已存 <路径>]`）：
   引导用户回复"解读"生成概览与全文产物；不要尝试自己解析该文件。

## 分工边界

- 解读/格式转换/OCR = 本模块（inbound 指令"解读"）
- 内容问答/总结/翻译/提取 = 你（agent），只读产物，不重复解析
- 用户说"解读 xxx"由模块接管，你收不到该消息（不进会话历史），正常回答其他问题即可
